Окно с прокруткой

Каскадные таблицы стилей задают внешний вид HTML-элементов: цвет, размер шрифта, отступы, границы и расположение блоков. Один внешний файл стилей можно подключить к нескольким страницам, поэтому дизайн сайта остаётся единым.

В этой работе для заголовков использован тёмно-синий цвет, для ссылок и акцентов — бирюзовый, а золотистый цвет выделяет активные элементы. Такие спокойные оттенки поддерживают деловой стиль и не мешают чтению.

Свойство overflow: auto создаёт прокрутку тогда, когда текста больше, чем помещается внутри блока. Высота окна ограничена стилем, поэтому содержимое демонстрирует работу прокрутки.

Адаптивные правила CSS меняют расположение блоков на узких экранах: две колонки становятся одной, а таблица при необходимости прокручивается по горизонтали. Благодаря этому сайт удобно просматривать и на компьютере, и на телефоне.

Классы textstyle0–textstyle4 показывают, как можно применить разные настройки к отдельным фрагментам текста, не повторяя оформление в каждом HTML-теге.

Вывод по работе

Роль CSS в создании веб-страниц

  1. CSS отвечает за визуальное оформление HTML-страниц.
  2. Стили задают цвета, шрифты, размеры, отступы и границы элементов.
  3. Внешний файл CSS позволяет использовать единый дизайн на нескольких страницах.
  4. Благодаря этому изменения не нужно вносить в каждый HTML-документ отдельно.
  5. Классы помогают применять нужное оформление только к определённым блокам.
  6. CSS делает структуру HTML понятнее, потому что содержание отделяется от дизайна.
  7. С помощью таблиц стилей можно быстро изменить цветовую гамму всего сайта.
  8. Правила адаптивности позволяют странице удобно отображаться на разных экранах.
  9. Свойство overflow помогает аккуратно размещать большой объём информации в ограниченном блоке.
  10. Псевдоклассы делают ссылки и кнопки заметнее при наведении.
  11. Таким образом, CSS ускоряет разработку и делает сайт более удобным и аккуратным.
